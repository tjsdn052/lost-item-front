State And Data Contracts

AgentInput

query, sessionId, hasImage, previousSlots, seedSlots를 받아 검색의 초기 상태를 만든다.

SearchSlots

물건명, 색상, 브랜드, 장소, 주소, 날짜 범위, 경찰청 코드값을 담는 agent 내부 검색 의도 모델이다.

FoundItemSearchPlan

follow-up 질문 여부와 호출할 OpenAPI tool 목록을 담는다. 물건명이 없으면 검색보다 추가 질문을 우선한다.

RankedFoundItem

원본 OpenAPI item, 점수, 매칭 근거를 함께 보관한다. GPT reranker는 이 후보 배열만 재정렬할 수 있다.

LostItemsSearchResult

UI가 소비하는 최종 결과다. 카드 목록, 세션 ID, assistant message, 검색 메타데이터를 포함한다.

Trust Boundary

LLM은 후보를 생성하지 않는다. candidateId가 기존 후보에 없으면 무시하고, 실패 시 결정론 랭킹을 그대로 사용한다.

Search Execution Details

검색 후보 생성
  • 룰 기반 추출과 OpenAI 슬롯 추출을 병합한다.
  • 이전 세션 슬롯과 이미지 기반 seed 슬롯을 함께 반영한다.
  • 물건명, 위치, 기간/지역/색상 검색을 병렬로 호출한다.
  • 경찰청 API와 포털기관 API 응답을 source label과 함께 합친다.
검증과 랭킹
  • 목록 응답에서 종결/반환 상태 후보를 먼저 제거한다.
  • 상위 후보는 상세 API와 Lost112 웹 상태를 다시 확인한다.
  • 결정론 점수는 이름, 색상, 장소, 날짜, 최신성을 반영한다.
  • GPT reranker는 검증된 후보 요약만 받아 최종 순서를 조정한다.

RAG Position

RAG는 검색 후보를 찾는 핵심 경로가 아니라, 사용자가 특정 후보를 선택한 뒤 “어떻게 찾으러 가야 하는지”를 안내하는 상세 안내 경로에서 사용된다.
